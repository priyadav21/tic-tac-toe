# Tic-Tac-Toe

A two-player Tic-Tac-Toe game built with React. Players take turns placing X
and O on a 3 × 3 board. The game highlights the active player, lets players
edit their names, records each move, and announces a win or draw. Start a
rematch after the game ends.

## Getting started

You’ll need [Node.js](https://nodejs.org/) and npm installed.

1. Install the dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm start
   ```

   Open the local URL printed in the terminal to play.

## Available scripts

- `npm start` — run the development server.
- `npm test` — run the test suite.
- `npm run build` — create a production build in `build/`.
